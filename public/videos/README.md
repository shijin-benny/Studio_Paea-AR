# Hero videos

Drop **MP4** (or .webm / .mov) files here. They are picked up automatically and rotate when each video ends.

- No config needed: add files, then run `npm run dev` (or `npm run build`) so the list refreshes.
- **Lazy loading:** only the current video is loaded; the next loads when it’s time to switch.
- Use **MP4** (H.264) for best compatibility.
- Videos play muted and advance to the next when the current one ends.
