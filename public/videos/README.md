# Hero videos

Drop **MP4** (or .webm / .mov) files here. They are picked up automatically and rotate on the homepage every 1 minute.

- No config needed: add files, then run `npm run dev` (or `npm run build`) so the list refreshes.
- Use **MP4** (H.264) for best compatibility and fast loading.
- Keep files reasonably sized (e.g. under 10MB each) for fast loading.
- Videos play muted and auto-rotate every 1 minute.
